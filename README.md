# OpsMemory

## AI Incident Response Agent That Learns From Every Incident

OpsMemory is an AI-powered incident response platform designed to help
engineering teams investigate recurring production incidents using persistent
memory.

The system uses Hindsight to retain incident knowledge, recall relevant
historical incidents, and provide context-aware investigation support.

## Core Flow

Incident
→ Analysis
→ Hindsight Recall
→ Investigation
→ Resolution
→ Postmortem
→ Hindsight Retain
→ Better Future Investigations

## Technology

- FastAPI
- Python
- Hindsight
- LLM
- Next.js
- TypeScript
